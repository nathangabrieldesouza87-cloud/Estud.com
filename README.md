# 🎓 Estud

> **Cada resposta é uma aula.**

O Estud é uma plataforma de inteligência artificial criada para ensinar de verdade.

Ao invés de simplesmente responder perguntas, o Estud explica os conteúdos passo a passo, adapta as explicações ao nível do aluno e acompanha sua evolução ao longo do tempo.

## Objetivos

- 📚 Ensinar qualquer matéria
- 🧠 Adaptar o ensino ao aluno
- 🎯 Criar planos de estudo
- 📝 Gerar exercícios
- 📊 Medir evolução
- 🤖 Professor virtual inteligente
- 🏆 Gamificação

## Tecnologias

- Frontend: Next.js
- Backend: FastAPI
- Banco de Dados: PostgreSQL
- IA: OpenAI API (ou outro modelo compatível)
